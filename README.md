### L-space knots

This repository stores the list of all L-space knots in the knot table up to 19 crossings along with their DT code in SnapPy's alphabetic convention. For knots with at most 16 crossings, we use the naming convention in the Hoste-Thistlethwaite table; for knots with more than 16 crossings, we use the naming convention in the [Burton table](https://regina-normal.github.io/data.html).

The list is generated by computing the knot floer homology for all knots in the said table, which determines wether a knot is an L-space knot or not, see ```is_L_space_knot.py``` for the code. The computation took about a week in 300 threads.
